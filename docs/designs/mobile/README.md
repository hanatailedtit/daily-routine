# Daily Routine · 모바일 UI 디자인

[전체 디자인 SVG](mobile-designs.svg) · [PNG 미리보기](mobile-designs.png) · [와이어프레임 버전](../../wireframes/mobile/mobile-wireframes.svg)

승인된 [데스크톱 디자인](../desktop/README.md)의 블루·쿨 그레이, Pretendard, 둥근 카드와 단일 강조색 규칙을 모바일에 이어 적용했습니다. 기존 `use-design-md`·`frontend-design` 작업에서 정한 제품의 시각 언어를 사용했으며, 다른 브랜드 스타일이나 새 기능은 추가하지 않았습니다.

기준 뷰포트는 390 × 844, 전체 보드는 1362 × 3224입니다. 긴 화면은 스크롤 전체 길이를 담았습니다. 모바일 배치의 흐름과 구현 참고 사항은 [와이어프레임 설명](../../wireframes/mobile/README.md)에 정리했습니다.

**이 SVG를 기준으로 실제 모바일 웹 화면에 적용했습니다.** 로그인 버튼을 첫 화면에 배치하고, 1024px 미만에서는 에디터를 단독 화면으로 표시합니다. 데이터·기능은 기존 Google 인증, 카테고리, 2단계 할 일, 서식 에디터와 프로필·통계에 맞췄습니다.

## 시각 규칙

| 역할 | 값 |
| --- | --- |
| 기본 텍스트 | `#191F28` |
| 설명·보조 텍스트 | `#4E5968` |
| 주요 행동·선택 텍스트 | `#1065CC` |
| 완료 체크·데이터 강조 | `#3182F6` |
| 선택·로그인 소개 표면 | `#E8F3FF` |
| 배경·보조 버튼 | `#F2F4F6` |
| 카드 | `#FFFFFF` |
| 구분선 | `#E5E8EB` |

색상 출처·대비 보정을 위해 선택한 역할·sRGB 근사값의 근거는 [데스크톱 디자인 설명](../desktop/README.md)에 있습니다. 모바일 배치와 단독 에디터 구성은 프로젝트의 추가 디자인 판단이며 원본 브랜드의 공식 규격을 의미하지 않습니다.

Pretendard를 기본으로 제목 28/36px, 섹션 20px, 본문 16px, 보조 정보 13/14px를 적용했습니다. 카드 반경은 24px, 버튼은 14/16px입니다. 메뉴와 에디터 외의 장식성 그림자·그라디언트를 추가하지 않았습니다. 미완료 통계에는 패턴·범례·수치를 병기했습니다.

## 파일과 검수

브라우저에서 열거나 Figma로 가져올 수 있는 SVG입니다. 텍스트와 도형은 편집 가능한 벡터 요소이며 Google 로고만 기존 프로젝트 PNG를 포함했습니다. 외부 이미지·폰트 요청이나 스크립트는 없습니다. Pretendard가 설치되지 않은 환경에서는 대체 글꼴로 인해 글자 폭이 조금 달라질 수 있습니다.

와이어프레임과 동일한 예시 데이터와 배치를 사용했습니다. SVG 구조·중복 ID·크기를 검사하고 PNG로 렌더링해 6개 화면을 검수했습니다. 주요 텍스트 조합의 대비는 4.5:1 이상입니다. SVG 제작 당시 앱 소스와 데스크톱 산출물의 해시가 동일한지 확인했습니다. 이후 별도 구현 작업에서 모바일 구성을 앱에 반영했습니다.

정적 디자인 산출물이므로 실제 스크롤·터치·메뉴 열기·키보드·OAuth 동작은 SVG에서 실행되지 않습니다. 다크 모드와 다른 모바일 폭의 개별 화면은 이번 산출물에 포함하지 않았습니다.
