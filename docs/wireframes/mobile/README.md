[전체 SVG](mobile-wireframes.svg) · [PNG 미리보기](mobile-wireframes.png) · [디자인 버전](../../designs/mobile/mobile-designs.svg)

기존 데스크톱 와이어프레임과 현재 앱의 기능을 기준으로 만든 **모바일 웹 구성안**입니다. 동일한 배치의 무채색 와이어프레임과 컬러 디자인을 각각 제공합니다. SVG 제작 이후, 이 구성을 실제 모바일 웹 화면에 반영했습니다. 데스크톱 SVG는 유지했습니다.

## 모바일 배치 제안

- 로그인: Google 버튼을 소개와 예시 목록보다 먼저 노출해 첫 화면에서 로그인할 수 있게 합니다. 이메일·비밀번호·별도 회원가입 링크는 없습니다.
- 내비게이션: 고정 사이드바를 왼쪽 메뉴 서랍으로 옮깁니다. 전체 할 일, 마이페이지, 카테고리와 프로필·로그아웃을 모았습니다.
- 목록: 통계는 2 × 2로, 할 일은 단일 열로 배치합니다. 하위 항목은 들여쓰기와 연결 아이콘으로 구분합니다. 수정·하위 추가·순서 변경·삭제는 더보기 메뉴로 모읍니다.
- 카테고리: 전체 목록과 별도로 선택된 업무 카테고리를 보여 줍니다. 이름 수정·카테고리 삭제와 할 일 추가를 구분합니다.
- 에디터: 오른쪽 패널을 단독 편집 화면으로 분리하는 제안입니다. 서식 도구는 두 줄로, 취소·변경 저장은 하단에 배치합니다. 새 할 일과 하위 할 일 작성도 같은 구조를 사용합니다.
- 마이페이지: 프로필, 2 × 2 요약, 완료 현황, 생성일별 상태, 카테고리별 현황을 한 열로 쌓습니다.

**로그인 우선 배치와 단독 편집 화면을 실제 앱에 반영했습니다.** 1024px 미만에서는 편집 시 목록을 숨기고 전체 화면 에디터를 사용합니다. 데스크톱에서는 기존 편집 패널을 유지합니다. 미저장 내용 확인, 뒤로 가기, 목록 스크롤 복원도 구현했습니다.

주요 버튼은 48px, Google·에디터 하단 버튼은 56px 높이입니다. 구현 시 아이콘 버튼과 체크박스 주변에는 44px 이상의 터치 영역을 확보하고, 메뉴에서 원래 화면으로 돌아갈 때 선택·스크롤을 유지합니다. 에디터에서 키보드가 나타날 때 본문과 저장 영역이 가려지지 않게 조정해야 합니다.

## 예시 데이터와 검수

상위 할 일 8개 / 완료 3개 / 미완료 5개 / 완료율 37.5%, 업무 4개 / 공부 2개 / 일상 2개, 하위 할 일 2개를 두 버전에 동일하게 사용했습니다. 날짜별 통계는 생성일로 묶은 현재 완료 상태이며 완료일 이력이 아닙니다.

SVG XML 파싱, 중복 ID, 스크립트·외부 요청 유무와 파일별 크기를 확인했습니다. PNG로 렌더링해 텍스트·버튼·차트 배치를 검토했습니다. 정적 산출물이며 실제 터치·가상 키보드·접근성 동작 검증은 포함하지 않습니다.
